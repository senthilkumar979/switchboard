# `@switchboard-js/api-mock`

Fetch interceptor that serves Switchboard API mock rules (global or scenario-effective).

## Install

```bash
pnpm add @switchboard-js/api-mock @switchboard-js/core
```

## Quick example

```ts
import { enableApiMock } from '@switchboard-js/api-mock';

const dispose = enableApiMock(switchboard);
```

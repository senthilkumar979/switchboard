# `@switchboard/api-mock`

Fetch interceptor that serves Switchboard API mock rules (global or scenario-effective).

## Install

```bash
pnpm add @switchboard/api-mock @switchboard/core
```

## Quick example

```ts
import { enableApiMock } from '@switchboard/api-mock';

const dispose = enableApiMock(switchboard);
```

# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Per-package release notes live in `packages/*/CHANGELOG.md`.

## [0.1.0] — 2026-10-16

First public release of:

- `@switchboard/core`
- `@switchboard/react`
- `@switchboard/devtools`
- `@switchboard/api-mock`

### Added

- Phase 1–4, 6 engine: feature flags, user simulation, scenarios, API mocks, React adapter, developer panel
- Phase 7: Changesets release workflow and publishable package metadata

### Changed

- Phase 5 (Angular) deferred; `@switchboard/angular` remains a private stub

See package changelogs for detailed notes.
